# 미션 - 점심 메뉴 추천

### 기능구현 목록

### 점심 메뉴 추천 기능

- [x] 코치의 이름을 입력받음
    - 예외1) 입력한 코치의 인원수가 2명에서 5명 사이가 아닐 경우
    - 예외2) 코치 각자의 이름이 2글자에서 4글자 사이가 아닐 경우
- [x] 각 코치가 못 먹는 메뉴를 입력받음
    - 예외1) 못 먹는 메뉴가 3개 이상 입력된 경우
    - 예외2) 입력한 메뉴가 원래 리스트에 없는 경우
- [x] 요일별 음식 카테고리 정함 (난수 사용)
- [x] 음식 카테고리와 못먹는 메뉴에 따라 추천할 점심 메뉴를 구성함
- [ ] 메뉴 추천 결과 출력
